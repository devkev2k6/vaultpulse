# VaultPulse AI — Chrome Browser Extension (Manifest V3)

This extension provides a live e-commerce companion that injects an **AI Savings & Trust Shield** onto shopping websites.

## 🚀 How to Install in Chrome (2 Steps)

1. Open **Google Chrome** and navigate to `chrome://extensions`.
2. Enable **Developer mode** (toggle in the top-right corner).
3. Click **Load unpacked** and select this `extension/` folder!

---

## ⚡ Features Injected
- **Seller Trust Meter**: Analyzes domain longevity, SSL certificate, and return SLA compliance.
- **Price Cross-Check**: Highlights price comparison savings.
- **Impulse Shopping Barrier**: Directly links checkouts to your active personal wealth goal.
- **Instant Sync**: Connects with your local VaultPulse AI web application (`http://localhost:3000`).
